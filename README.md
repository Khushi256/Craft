# CraftAI - E-Commerce Website

A modern, animated e-commerce frontend built with React, Vite, and Tailwind CSS.

## Demo

## Features

-  Interactive animations with Framer Motion
-  Responsive design with Tailwind CSS
-  Featured products, sales, and category sections
-  Circular gallery and liquid chrome effects
-  Accessible components with Radix UI
-  Lightning-fast builds with Vite

## Tech Stack

- **React** 19 + Vite 7 + Tailwind CSS 4
- Framer Motion for animations
- Radix UI + Lucide Icons
- OGL for WebGL effects

##  Installation

Follow these steps to run the project locally:

```bash
# 1️⃣ Clone the repository
git clone https://github.com/Khushi256/craft.git

# 2️⃣ Move into the project folder
cd craft

# 3️⃣ Install dependencies
npm install

# 4️⃣ Run the development server
npm run dev
```

## Components

- **Navbar** - Site navigation
- **HeroSection** - Landing banner with CTAs
- **FeaturedProducts** - Product showcase
- **Sale** - Promotional section
- **Category** - Product categories
- **CircularGallery** - 3D gallery experience
- **LiquidChrome & BlurText** - Visual effects
